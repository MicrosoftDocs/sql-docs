> [!IMPORTANT]
> Starting August 15, 2026, the AMQP protocol is deprecated for change event streaming (CES). All newly created stream groups must use `AzureEventHubs` as the `destination_type` to stream with the Apache Kafka protocol. For migration steps and timelines, see [AMQP protocol deprecation](../relational-databases/track-changes/change-event-streaming/amqp-deprecation.md).
