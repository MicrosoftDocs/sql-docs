# Analysis Server &lt;server&gt; (SQL Server Configuration Manager)

[!INCLUDE [SQL Server Windows Only](../../includes/applies-to-version/sql-windows-only.md)]

This is the service that supports Microsoft [!INCLUDE [ssASnoversion](../../includes/ssasnoversion-md.md)]. To view the properties of the service, right-click the service in the details pane, and then select **Properties**.

For information about [!INCLUDE [ssASnoversion](../../includes/ssasnoversion-md.md)], see [What is Analysis Services?](/analysis-services/analysis-services-overview)
