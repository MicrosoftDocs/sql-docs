Users can also use the following built-in roles:

- SqlVM Migration Role
- SqlMI Migration Role
- SqlDB Migration Role

These built-in roles enable users to:

1. Create and delete Database Migration Service (DMS) instances.
1. Execute database migrations by using DMS.
